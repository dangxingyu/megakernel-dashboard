# megakernel dashboard

Interim results page for a study of model-specific decode megakernels against general LLM inference engines.

Page: https://dangxingyu.github.io/megakernel-dashboard/

This is work in progress. Every number on the page is a trial run and may change; please do not redistribute.

`index.html` is a single self-contained file (inline SVG charts, no scripts from elsewhere). It is generated from
the project's job records; edit the generator, not this file.
